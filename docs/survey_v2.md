## 1. 설문이 바꿀 결정 5개 — 기준치를 먼저 적는다

문항은 이 표에서 거꾸로 나왔다. 결정에 연결되지 않는 문항은 전부 선택으로 두거나 뺐다.

**타겟 정의 (모든 판정에 공통):** Q1 = 「3~6번」 **그리고** Q2 ≠ 「없다」.

| | 결정 | 보는 문항 | 성공 → 행동 | 실패 → 행동 | 분모 |
|---|---|---|---|---|---|
| A | 1차 타겟(연 3~6회 관람 + 같은 작품 재관람)이 모이고 있나 | Q1, Q2 | 타겟 비율 **≥ 30%** → 지금 모집 채널 유지 | **< 30%** → 모집 채널 변경 | 완료 응답 전체(0번 응답 포함) |
| B | 조합 문제가 진짜 있나 | Q9 (보조: Q6, Q10, Q11) | 타겟 중 Q9 「예」 **≥ 40%** → 조합 추천 유지 | **< 40%** → 조합을 핵심에서 내리고 배우 1명·회차 추천으로 | 타겟 |
| C | 취향 축 3개가 쓸 만한가 | Q12 | 축별로 「3」 응답 **≤ 60%** → 그 축 유지 | **> 60%** → 그 축 폐기 | 타겟 (전체도 같이 보고 갈리면 보고) |
| D | 관람 후 태그·투표를 남길 의향이 있나 | Q16, Q17 | 4~5점 **≥ 30%** → 앱 안 입력 기능 설계 | **< 30%** → 수작업 수집 유지 | 타겟 |
| E | 캐스팅 확인 경로·예매처 → 배포 채널 | Q7, Q8 | 아래 제안 | 아래 제안 | 타겟 |

**D는 문항별로 적용한다(내 해석):** 태그(Q16) ≥ 30%면 태그 입력만, 투표(Q17) ≥ 30%면 투표만 앱 안에 넣고, 둘 다 < 30%면 수작업 수집을 유지한다.

**E의 기준치는 합의된 게 없어서 내가 제안한 값이다 — 팀 확인 필요:**
- Q7에서 1위 경로가 타겟의 **50% 이상** → 그 경로의 형식(예: 이미지 일정표)에 맞춰 입력·공유를 설계하고 첫 배포도 그 채널에서 한다. **50% 미만**(분산) → 한 경로에 맞추지 않고 링크로 공유되는 결과 카드를 기본 출력으로 둔다.
- Q8에서 1~2위 예매처 합이 **70% 이상** → 예매 딥링크는 그 두 곳만 연결한다.

**판정 규칙**
- 타겟이 30명이면 40%의 95% 신뢰구간이 약 ±17%p다(12/30). 그래서 **기준치 ±5%p 안(A 25~35 / B 35~45 / C 55~65 / D 25~35%)은 판정하지 않고 모집을 연장**한다.
- Q2는 「다른 캐스트로 다시 본 적」이라 「같은 작품 재관람」보다 좁다. A는 일부러 보수적으로(타겟을 작게) 센다.
- D는 의향이라 실제 행동보다 후하게 나온다. ≥ 30%여도 베타에서 실측으로 다시 확인한다.
- 모집 채널(뮤지컬 X·커뮤니티)이 헤비 관객 쪽으로 쏠려 있어 A는 실제보다 높게 나올 수 있다. A가 30%를 못 넘으면 정말 이 채널의 문제다.
- Q1 「7번 이상」은 2차 타겟(기획서의 중급 이상 관객)이라 타겟 집계에서는 빠진다. 대신 B·C·D를 이 집단에서도 같이 뽑아, 타겟과 결과가 갈리는지만 본다.

### S2. 조합 가설

**Q11 · 필수 · 객관식(1개, 강제선택)** — 결정 B 보조(추천 단위·첫 화면 우선순위)
> 추천을 딱 한 가지만 받을 수 있다면, 어느 쪽이 예매 결정에 더 도움이 될까요?

질문 아래에 카드 두 장을 그대로 붙인다(이미지로 만들면 더 좋다 — 문구는 그대로 쓴다). 두 카드는 줄 수와 정보량을 맞췄다.
```
[카드 ① 배우 1명 추천]
엘리자벳 · 죽음 역
추천 배우: ○○○
· 내 취향과 맞는 점: 가창 중심 · 맑은 음색
· 이 배우가 나오는 날: 10/11(토) 19:00 외 3회
· 근거: 관람 후 태그 2건

[카드 ② 조합 + 회차 추천]
엘리자벳 · 10/11(토) 19:00
엘리자벳 ○○○ + 죽음 △△△ + 루케니 □□□
· 내 취향과 맞는 점: 가창 중심 · 감정을 크게 표현
· 이 조합의 포인트: 두 주연의 음색 대비가 커서 듀엣이 돋보였다는 태그
· 근거: 관람 후 태그 3건
```

보기
- 카드 ① 배우 1명 추천이 더 도움이 된다
- 카드 ② 조합 + 회차 추천이 더 도움이 된다
- 둘 다 별로 도움이 안 된다

설정: 보기 순서 섞기 켬. 「둘 다 별로」는 강제선택에서 빠져나갈 길이라 일부러 둔다(캐스팅에 관심 없는 응답이 한쪽으로 섞이지 않게). 분석은 ①과 ②만 비교한다. 카드를 보여 주는 순서의 영향은 통제하지 못한다(§6).

### S3. 평소 취향

섹션 제목: 평소 어떤 배우에게 끌리세요?
섹션 설명: 특정 작품이 아니라, 평소 취향을 여쭤봐요. 가운데인 3은 「두 쪽이 비슷하다」는 뜻이에요.

**Q12 · 필수(3행 모두) · 객관식 그리드(행 3개 × 열 5개)** — 결정 C
> 특별히 좋아하는 배우가 없다고 생각하고, 두 가지 중 어느 쪽에 더 끌리는지 골라 주세요.

열(왼쪽부터): 1 왼쪽이 훨씬 / 2 왼쪽이 조금 / 3 두 쪽이 비슷하다 / 4 오른쪽이 조금 / 5 오른쪽이 훨씬

행
- 노래(가창)가 중심인 배우 ↔ 연기가 중심인 배우
- 감정을 크게 터뜨리는 연기 ↔ 감정을 눌러 담는 절제된 연기
- 맑고 깨끗한 음색 ↔ 허스키하거나 묵직한 음색

설정: 「행마다 응답 필요」 켬. 점수화는 1·2 = 왼쪽, 4·5 = 오른쪽, 3 = 쓰지 않음. `recommend.py`의 `AXIS` 키와 1:1로 맞는다(가창/연기 · 감정 크게/절제 · 맑은 음색/묵직한 음색).

**Q13 · 선택 · 단답** — 결정 없음(시드 10작품의 배우 커버리지 점검용)
> 좋아하는 배우가 있다면 최대 3명까지 적어 주세요. (쉼표로 구분)

**Q14 · 선택 · 체크박스(복수)** — 결정 없음(기능 우선순위: 공식 영상 모아보기를 얼마나 앞에 둘지)

- 연기·공연 영상(프레스콜·하이라이트 등)을 찾아본다
- SNS·커뮤니티 후기를 찾아본다
- 배우의 이전 작품을 찾아본다
- 지인에게 추천받는다
- 유명하거나 익숙한 배우를 고른다
- 시간·날짜가 맞는 회차를 먼저 고른다

- 크게 고민하지 않는다
- 기타 (직접 입력)

설정: 「기타」 직접 입력 켬.

## 5. 배포 계획

| 항목 | 기준 |
|---|---|
| 목표 | 완료 응답 **100명 이상**, 그중 **타겟 최소 30명**. A가 30%면 100명이 있어야 타겟 30명이 나온다. 타겟이 30명이 안 되면 모집을 연장한다 |
| 채널 | 뮤지컬 X(트위터)와 뮤지컬 커뮤니티에 모집 글, **1주**. 커뮤니티는 게시 전에 운영 규칙(설문·홍보 글 허용 게시판)을 확인하고, 규칙이 막으면 올리지 않는다 |
| 지인 비중 | **50% 미만**. 지인에게 보내는 링크는 폼을 복제한 「지인용 폼」(같은 문항)으로 나눠 응답 시트를 분리하고 비중을 센다. 문항 수를 늘리지 않으려고 「어디서 보셨나요」는 묻지 않는다 |
| 소요 | **4분 이내** |

**진행 순서**
1. 사전 테스트: 팀 밖 3명이 스톱워치로 끝까지 푼다. 중앙값이 4분을 넘으면 선택 문항부터 뺀다 — 순서: Q10 → Q15 → Q14 → Q5 → Q13.
2. 배포 1일차~7일차. 3일차에 타겟 수를 본다(10명 미만이면 채널을 하나 더 붙인다).
3. 7일차 마감 → §1 표대로 5개 결정을 판정 → 보류 구간은 모집 연장.
