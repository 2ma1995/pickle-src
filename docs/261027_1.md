## 3. 최종 온보딩 구조 (`app/index.html`)

**1/3 보고 싶은 배우가 있나요?**
- 꼭 보고 싶은 배우: 배우별 **반드시 포함 / 가능하면 포함**
  - 반드시 포함 → 그 배우가 주연으로 나오는 조합만 추천(⭐와 같은 규칙). 그 작품에 안 나오면 거르지 않음
  - 가능하면 포함 → 거르지 않음(기존 ‘좋아하는 배우’와 같음)
- 피하고 싶은 배우(선택) → 그 배우가 나오는 회차는 조연이어도 추천에서 제외. 홈 ‘닮은 배우’ 추천에서도 제외
- 같은 배우를 양쪽에 둘 수 없음(옮기면 반대쪽에서 빠짐)

**2/3 어떤 공연이 끌려요?** — 기존 공연 카드 그대로

**3/3 이번 관람에서 무엇을 기대하나요?**

| 질문 | 선택지 → 태그 |
| --- | --- |
| 가장 기대하는 것은 무엇인가요? (1개) | 노래 / 연기·캐릭터 표현 / 춤·몸짓 / 골고루 |
| 어떤 목소리에 더 끌리나요? (2개까지) | 맑고 깨끗한→맑음 · 부드럽고 따뜻한→부드러움 · 허스키하고 거친→허스키 · 낮고 묵직한→묵직한 음색 · 선명하고 쨍한→선명하고 쨍한 음색 |
| 노래를 들을 때 특히 중요한 점은? (2개까지) | 시원한 고음→고음 · 공간을 채우는 성량→성량 · 또렷한 가사→딕션 · 흔들림 없는 발성→발성 안정성 · 감정이 전해지는 노래→감정 전달형 · 섬세한 강약·호흡→섬세한 가창 표현 |
| 어떤 감정 표현에 더 끌리나요? (2개까지) | 감정을 크고 강하게 드러내는→감정 크게 표현 · 감정을 눌러 담는→절제된 연기 · 유쾌하고 코믹한→코믹 연기 |
| (접힘) 움직임에서는 무엇을 보고 싶나요? | 춤·안무→춤·안무 표현 · 시원한 액션→액션 표현 · 자세·걸음·손짓의 디테일→자세·동작 디테일 · 표정·시선의 디테일→표정·시선 디테일 |
| (접힘) 인물을 어떤 방식으로 보여주면 좋겠나요? | 실제 사람처럼 자연스럽게→현실적·생활감 · 개성과 욕망을 선명하게→강한 캐릭터성 · 작은 표정과 몸짓으로 내면의 변화를→섬세한 내면형 · 상대 인물과의 관계를 중심으로→관계 중심 |
| (접힘) 두 배우가 함께할 때 무엇이 가장 중요한가요? | 노래의 어우러짐→음색·보컬 조화 · 주고받는 연기→연기합·티키타카 · 감정선 연결→감정선 조화 · 이미지·분위기→이미지·분위기 조화 · 서로 다른 매력의 대비→대비 시너지 |

- 질문마다 ‘상관없어요’는 그 질문만 비움, 3번째 선택은 막고 안내
- 근거 0건 선택지는 ‘아직 데이터 없음’(필수 질문), 선택 질문에서는 숨김. 근거가 하나도 없는 선택 질문은 통째로 숨김
- ①에서 춤·몸짓을 고르면 움직임 질문은 접지 않고 바로 보임
- 선택 질문은 ‘조금 더 골라 보기’로 펼침(‘더 정확하게’는 기존 문구 금지어라 바꿈). 한 번 펼치면 다시 그려도 펼친 채 유지

## 4. 추천 점수 변경 (`comboRecs`, `comboEvidence`)

- **취향 키**: 새 질문은 `tag:태그` 형식. 5축 키 ‘묵직한 음색’(= 허스키+묵직한 음색)과 태그 ‘묵직한 음색’이 겹쳐서 접두어로 구분. 예전 5축 키는 그대로 동작
- **우선순위 가중치(대충 버전)**: 1순위 영역 질문에서 고른 태그는 (배우, 취향) 쌍마다 2점, 나머지 1점
  - 노래 = 음색·가창 질문 / 연기 = 감정 표현·캐릭터 해석 질문 / 춤·몸짓 = 움직임 질문
  - 골고루·안 고름·조합 질문·예전 5축 키는 1점
- **배역 싱크로**: 배우마다 +0.5. 취향 근거가 있는 조합에만 붙고 이것만으로는 추천하지 않음. ‘설명이 틀렸어요’로 뺀 배우는 안 셈
- **반대 근거(△)**: 새 `tag:` 키는 반대쪽이 정의되어 있지 않아 표시되지 않음(비선호 문항을 없앤 결정과 맞음)
