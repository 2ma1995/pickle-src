### 2.3 배우 사진 · 날짜 먼저 세 화면 · 폰 포스터 (결정 70~74, 배포 15:35)

- **추천 조합 카드:** 날짜·시간 밑에 배우마다 동그란 사진 → 이름 → 배역(배역 → 배우 한 줄 글을 대신함). 배우 먼저의 피하고 싶은 배우 칩에도 같은 사진.
- **사진 출처:** 위키미디어 공용(Wikimedia Commons)의 자유 이용 사진만. 이름으로 자동 매칭하면 다른 사람이 걸려서(카이 → EXO 카이, 민영기 → 조선 정치인, 이창호 → 바둑 기사, 장윤석 → 기업인) 설명·직업으로 확인한 위키데이터 ID 14명만 쓴다(`actor_photos.py`의 `APPROVED` → `data/actor_photos.tsv`). 14장은 한 사람만 찍힌 사진인지 눈으로 확인했다. 저작자·라이선스는 「배우 사진 출처」 화면(`#photos`), 링크는 카드 아래가 아니라 내 취향 맨 아래 작은 글씨.
- **날짜 먼저 세 화면:** ① `#find/작품/date` 날짜 고르기 → [다음 · N일의 추천 조합 보기] → ② `/date/recs` 고른 날짜의 추천 조합(고른 날짜 요약 + 「날짜 다시 고르기」) → [이 조합 고르기] → ③ `/date/cal` 그 조합의 캘린더만.
- **날짜 고르기:** 탭 순서 [기간 | 하루씩], 기간이 기본. 기간을 고를 때마다 그 사이 회차 있는 날이 더해진다(여러 기간). 하루씩 탭이나 날짜 칩 ×로 하루씩 빼고 더한다. 달력 아래 「볼 수 있는 날짜를 여러 개…」 안내는 지우고, 기간 시작일을 누른 뒤에만 「끝 날짜를 눌러 주세요」.
- **포스터 격자:** 팀원이 한 줄 5개로 바꾼 것 중 폰(600px 미만)만 원래대로 한 줄 3개. 넓은 화면은 5개 그대로.

## 3. 하지 않은 것 · 이유

- **나무위키·네이버·NOL 배우 사진:** 대부분 언론사·소속사가 저작권을 가진 사진이고 그 사이트 안에서만 공정 이용으로 쓰인 것이라 우리 서비스에 가져다 쓰지 않았다. 초상권과 각 사이트 약관 문제도 있다.
- **사진 출처 지우기:** 위키미디어 사진은 출처 표시가 사용 조건이라 출처 화면은 남겼다(카드 아래 링크만 뺌). 출처 없이 쓰려면 제작사·소속사에게 허락받은 사진이나 출처 표시가 필요 없는 사진(CC0)만 쓸 수 있다.
- **티켓북처럼 펼쳐지는 디자인:** 가능 여부만 답했다. 스크롤에 맞춰 움직이는 애니메이션(GSAP ScrollTrigger)과 CSS 3D로 만들 수 있고, 홈 한 화면 시안 1~2일, 주요 화면까지 4~6일 + 조정 1~2일. 참고 링크는 직접 열어 보지 못해서 움직임 설명이나 화면 녹화가 필요하다.
